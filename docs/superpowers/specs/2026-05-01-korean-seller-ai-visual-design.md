## 1. 제품 정의

### 한 줄 정의
> **한국 스마트스토어/쿠팡 셀러용 AI 라이프스타일 사진 생성 SaaS.**
> 상품 누끼컷을 업로드하면, 한국 인테리어/한국 셀러 톤에 맞춘 라이프스타일 사진 4종을 30초 안에 자동 생성한다.

### 해결하는 문제
한국 1인 셀러는 신상마다 라이프스타일 사진이 필요하다. 현재 옵션:
- **외주 모델 촬영**: 회당 30~100만원, 1~2주 소요
- **포토샵 직접 합성**: 시간 소모 + 결과물 품질 편차
- **Photoroom 같은 해외 AI 도구**: 결과물이 서양 인테리어/서양 모델 톤이라 한국 e커머스에 그대로 쓰기 어려움

우리는 **한국 톤 학습된 AI + 셀러 워크플로우 특화**로 이 빈틈을 메운다.

### 비즈니스 모델
- B2C SaaS 월 구독 (MRR 누적형)
- 핵심 가격: Pro 29,000원/월 (목표 사용자 70%)
- 12개월 목표: 유료 250명, MRR 800만원

## 2. 타겟 페르소나

### Primary: 성장기 1인 셀러 "지영"

| 항목 | 정의 |
|---|---|
| **나이/형태** | 30~40대, 1인 셀러 (부업 시작 1~3년차, 본업 전환 중) |
| **매출 단계** | 월 500만~3,000만원 |
| **신상 출시 빈도** | 주 1~3회 |
| **현재 비주얼 작업 방식** | 외주 모델 촬영(30~100만원/회) + 본인 포토샵 합성 |
| **월 비주얼 외주 비용** | 50~200만원 |
| **결제 의사** | $29-49/mo는 부담 없음. ROI 명확하면 $99도 가능 |
| **사용 빈도(예상)** | 신상마다 = 주 1~3회 |
| **기술 수준** | PC/스마트폰 능숙, 포토샵 기본만, AI 도구 호기심 있음 |
| **도달 채널** | 셀러 카페(아이보스, 셀러오션), 유튜브(이커머스 강의), 네이버 검색 |

### 제외 페르소나 (의도적)

| 페르소나 | 제외 사유 |
|---|---|
| 신규 셀러 (월매출 100만원 이하) | 결제력 약함, 무료 도구 선호 |
| 안정 셀러 (월매출 3,000만원+) | 외주 시스템/직원 보유, 우리 도구 매력 약함 |
| 대형 브랜드/엔터프라이즈 | 영업 사이클 길고 1인 운영 부적합 |

## 3. MVP 기능 + 사용자 흐름

### V1 카테고리 우선순위
AI 결과 품질 기준으로 좁게 시작:

1. **🥇 리빙/홈데코** (가구, 데코, 주방용품, 수납) — V1 메인
2. **🥈 소형 가전** (선풍기, 가습기, 무드등, 미니 가전) — V1 메인
3. **🥉 뷰티/퍼스널케어** (사람 얼굴 없는 제품샷 한정) — V1 메인
4. 유아동 용품 (모델 없는 제품 위주) — V1.1
5. 반려동물 용품 — V1.1
6. ❌ 의류 — V2 이후 (AI 핏 표현 한계)
7. ❌ 식품/신선식품 — V2 이후 (디테일 깨짐)

### 핵심 사용자 흐름

```
[가입(구글/카카오)]
   ↓
[온보딩: 카테고리 선택, 1분]
   ↓
[메인 화면 — "새 라이프스타일컷" 버튼]
   ↓
[누끼컷 1장 업로드]
   ├─ 누끼 안 된 상품 사진? → [자동 누끼 도구] (BiRefNet)
   ↓
[옵션 선택]
   • 분위기: 모던 / 내추럴 / 빈티지 / 미니멀 / 코지 (5종)
   • 환경: 거실 / 침실 / 주방 / 책상 / 욕실 (5종)
   ↓
[생성] → 20-40초 대기
   ↓
[결과 4종 변형 표시]
   ↓
[1개 선택] → [JPG/PNG 다운로드]
   • 자동 갤러리 저장
   • "다시 생성"(같은 옵션, 새 변형) 가능 — 사용량 차감
```

### V1에 포함되는 화면
1. 랜딩페이지 (마케팅용)
2. 가입/로그인 (구글, 카카오 OAuth)
3. 온보딩 (3단계: 환영 → 카테고리 선택 → 첫 생성 가이드)
4. 대시보드 / 갤러리 (이전 생성물 + 사용량 카운터)
5. 새 생성 화면 (업로드 + 옵션 + 생성 + 결과)
6. 결제/플랜 페이지 (토스페이먼츠 연동)
7. 설정 (계정, 결제 관리, 사용량)

### V1 미포함 (후속 버전)

| 기능 | 추가 시점 |
|---|---|
| 모델컷 (사람 합성) | V2 (M4) |

## 4. 차별화 (Moat)

### 경쟁사 비교

| 항목 | Photoroom (해외) | 망고보드/미리캔버스 (한국) | **우리** |
|---|---|---|---|
| 한국 인테리어 톤 | ❌ 서양식 | ❌ 일반 템플릿 | ✅ 한국식 거실/주방 학습 |
| AI 자동 생성 | ✅ | ❌ (수동 편집) | ✅ |
| 셀러 워크플로우 특화 | ❌ | ❌ | ✅ 스마트스토어/쿠팡 규격 자동 |
| 한국 결제 | ❌ | ✅ | ✅ 토스/카카오 |
| 가격 (월) | $14 | 17,000원~ | 29,000원 (Pro) |

### Moat 3가지

1. **한국 인테리어/톤 큐레이션 프리셋**
   - 디자인 감각으로 직접 큐레이션한 한국식 분위기 프리셋
   - **V1 출시**: 분위기(5종) × 환경(5종) = 조합 25개 + 카테고리별 prompt 변형 = **약 50개 프리셋**
   - **M3까지**: 사용자 인기 조합 보고 100개로 확장
   - 모방 가능하지만 디자인 품질로 격차 유지
   - 사용자 결과물 데이터 누적 → 재학습 → 점점 한국 톤 잘함

2. **셀러 특화 출력 규격**
   - 스마트스토어 권장 사이즈, 쿠팡 권장 사이즈, 인스타 광고 사이즈 자동 맞춤
   - 일반 디자인 도구 못함

3. **셀러 카페 신뢰 (네트워크 효과)**
   - 베타 단계부터 셀러 카페 후기 누적
   - 후기 → 신규 가입 → 후기 가속 (반복)
   - 후발 주자가 카피하기 어려운 비대칭 자산

### 솔직한 한계
- AI 모델 자체는 Replicate 공유 자원 → 기술적 moat 낮음
- 차별화는 **(디자인 큐레이션) × (셀러 특화) × (한국 커뮤니티 신뢰)** 곱으로 만들어짐
- 단일 요소로는 카피 가능, 곱으로 누적되면 어려움

## 5. 기술 아키텍처

### 스택 선택

| 영역 | 선택 | 이유 |
|---|---|---|
| **프론트엔드** | Next.js 14 (App Router) + TailwindCSS + shadcn/ui | 풀스택 빠른 개발, Vercel 배포 |
| **백엔드** | Next.js API routes (MVP는 분리 불필요) | 단일 코드베이스 |
| **DB** | Supabase (Postgres) | 인증 + DB 통합, 무료 시작, 스케일 가능 |
| **이미지 저장** | Cloudflare R2 | S3 호환, 다운로드 트래픽 무료 |
| **큐/카운터** | Upstash Redis | 사용량 제한, 생성 큐 |
| **AI 이미지 생성** | Replicate API (FLUX + ControlNet) | 빠른 출시 우선, 누끼 보존 가능 |
| **AI 누끼 제거** | Replicate (BiRefNet) | 사용자가 누끼 안 만든 경우 자동 |
| **결제** | 토스페이먼츠 (정기결제) | 한국 시장 한정. Stripe는 V2+ 글로벌 확장 시 추가 |
| **모니터링** | Sentry + PostHog | 에러 추적 + 사용자 행동 분석 |
| **이메일** | Resend | 트랜잭셔널 이메일 |

### 데이터 모델 (핵심 테이블)

- `users` — 가입자 정보, 플랜, 사용량 카운터
- `brands` — 사용자 브랜드 설정 (카테고리, 톤 선호)
- `generations` — 생성 이력 (입력 이미지, 옵션, 출력 4종, 비용)
- `subscriptions` — 결제/플랜 상태
- `usage_logs` — 일별/월별 사용량 (rate limit + 마진 모니터링)

### 비용 구조

| 항목 | 단가 | 비고 |
|---|---|---|
| FLUX 1장 생성 | ~$0.03 | Replicate Public model |
| 4종 변형 = 1번 생성 | ~$0.12-0.20 | 사용자 1번 클릭 = 4종 출력 |
| BiRefNet 누끼 | ~$0.005 | 사용자가 누끼 안 만든 경우만 |
| Supabase 무료 한도 | 500MB DB | 초기 충분 |
| R2 스토리지 | $0.015/GB | 1만 사용자 = ~$50/mo |

### 마진 시뮬레이션

| 플랜 | 가격 (월) | 월 100% 사용 시 원가 | 마진 |
|---|---|---|---|
| Free | 0 | ~$1 (5장 × $0.20) | 손실 (마케팅 비용으로 간주) |
| Starter | 9,900원 (~$7.5) | ~$6 (30장) | $1.5 |
| **Pro** | 29,000원 (~$22) | ~$20 (100장) | **$2** ⚠️ |
| **Plus** | 59,000원 (~$45) | ~$60 (300장) | **-$15** ⚠️ |

⚠️ **마진 안전장치 (V1 출시 시 적용)**:
1. **Plus 한도를 500장 → 300장으로 조정** (스펙 v0.1에서 500장이었으나 마진 문제로 V1 출시 시점에 300장으로 확정)
2. **실제 사용률 모니터링** — 대부분 사용자는 한도의 30-50%만 사용하는 게 일반적. 100% 사용은 소수.
3. **M3까지 실사용 패턴 보고 가격/한도 미세조정**
4. **M6 이후 Replicate → RunPod 자체 호스팅** 검토 (이미지 1장 비용 60-70% 절감 기대)
5. **이미지 캐싱** — 비슷한 옵션 조합은 일부 결과 재사용

### 핵심 외부 의존성 리스크

| 의존성 | 리스크 | 완화책 |
|---|---|---|
| Replicate API | 가격 인상, 모델 deprecation | 자체 호스팅 옵션 사전 검증 (M6) |
| FLUX 모델 라이선스 | 상업 사용 제한 변경 | 라이선스 정기 점검, 백업 모델(SDXL) 준비 |
| Supabase | 가격 정책 변경 | DB 표준 Postgres라 이전 가능 |
| 토스페이먼츠 | 한국 한정 | V2+에서 Stripe 추가 |

## 6. 가격

### 플랜 구조

| 플랜 | 월 가격 | 월 생성 | 워터마크 | 브랜드 | 우선순위 큐 |
|---|---|---|---|---|---|
| **Free** | 0원 | 5장 | ✅ 있음 | 1개 | 일반 |
| **Starter** | 9,900원 | 30장 | ❌ 없음 | 1개 | 일반 |
| **Pro** ⭐ | **29,000원** | 100장 | ❌ | 3개 | 우선 |
| **Plus** | 59,000원 | 300장 | ❌ | 무제한 | 우선 |

- 연간 결제 20% 할인 (≈ 2.4개월 무료)
- Free는 평생 무료, 워터마크 + 5장 한도
- 목표 사용자 분포: Free 60% / Starter 15% / **Pro 20%** / Plus 5%
- **사용량 카운터 reset**: 결제 갱신일 기준 (예: 매월 15일 결제 사용자 → 15일에 카운터 0으로 리셋). Free 사용자는 가입일 기준.
- **한도 초과 시**: 다음 갱신일까지 생성 차단. 추가 사용량 패키지(예: +50장 9,900원) 옵션 제공 (V1.1).

### 가격 가설 (검증 필요)

- 29,000원이 한국 셀러에게 "월 외주 비용 50-200만원의 1.5%"로 인식되어 결제 부담 낮을 것
- M3 시점 실제 결제 패턴 보고 조정 (5,000원 단위로 A/B 테스트)

## 8. 성공 지표 (체크포인트)

### 핵심 KPI

| 지표 | 목표 | 미달 시 대응 |
|---|---|---|
| 무료 → 유료 전환율 | ≥ 5% | 가치 제안 또는 가격 재검토 |
| 월 churn (유료) | ≤ 8% | stickiness 기능 강화 (갤러리/브랜드 자산) |
| WAU/가입자 | ≥ 30% | 온보딩 + 푸시 알림 개선 |
| 사용자당 월 생성 횟수 | ≥ 15회 | 사용 동기 부족 → UX 개선 |
| NPS (M6 시점) | ≥ 30 | 결과 품질 또는 워크플로우 재검토 |

### 체크포인트 게이트

- **M3**: 유료 전환율 5% 미달 → 가격/플랜 재설계 또는 페르소나 재검증
- **M6**: MRR 250만원 미달 → 채널 전략 전환 (커뮤니티 우선 → 광고 우선)
